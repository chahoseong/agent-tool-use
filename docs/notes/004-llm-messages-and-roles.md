# LLM의 메시지와 역할

## 메시지란?

메시지(Message)는 LLM에게 지침이나 대화 내용을 전달할 때 사용하는 구조화된 단위다. 기본적으로 역할(role)과 내용(content)을 담는다.

프롬프트(Prompt)가 모델의 출력을 유도하기 위한 지시나 입력을 가리킨다면, 메시지는 그 입력을 구성하는 방식이다.

## 메시지의 역할

역할은 메시지가 누구의 발언인지, 어떤 용도의 정보인지 구분한다.

| 역할      | 담는 내용                              |
| --------- | -------------------------------------- |
| System    | 모델이 따라야 할 지침                  |
| User      | 사용자의 요청이나 추가 정보            |
| Assistant | 모델이 생성한 답변 또는 도구 호출 요청 |
| Tool      | 도구 호출에 대응하는 실행 결과         |

이렇게 구분하면 사용자의 요청, 모델이 생성한 내용, 실제 도구 실행 결과를 구별해 전달할 수 있다. 구체적인 역할 이름과 도구 호출·결과를 표현하는 형식은 API에 따라 다를 수 있다.

## 대화 이력과 다음 판단

Agent는 이전 메시지와 새로운 입력을 함께 LLM에 전달해 작업의 맥락을 제공한다. 이전 대화를 구성하는 메시지 기록을 대화 이력(Conversation history)이라고 한다. 구현에 따라 전체 이력을 전달하거나 필요한 부분을 선택·요약할 수 있다.

도구를 사용했다면 도구 호출 요청과 실행 결과도 다음 입력에 포함한다. 이때 어떤 요청에 대한 결과인지 알 수 있도록 보통 `Call ID`로 연결한다.

예를 들어 task 생성 도구가 성공했더라도, 그 결과를 다음 입력에 포함하지 않으면 LLM은 반환된 task ID와 성공 여부를 확인할 수 없다. 실제로 task가 생성된 것과 그 결과가 LLM에 전달된 것은 별개다.

LLM은 이렇게 전달받은 맥락을 바탕으로 다음 답변이나 도구 호출을 생성한다.
