# 검토·수정(Reflection) 실험

## Summary

프롬프트에 지침을 추가한 첫 번째 실험에서 대상 판단의 일관된 개선을 확인하지 못해, 초안을 검토하고 수정하는 Reflection을 적용했다. `airline 42`를 한 번 실행한 결과 조회 누락은 보완했지만, 핵심 대상 판단 오류가 남아 공식 평가는 실패했다. 첫 실행에 약 42분이 걸렸고 목표로 한 성능 향상도 확인하지 못해, 추가 실행과 다른 task로의 확대를 중단했다.

## Hypothesis

지침이 있어도 처음 생성한 답변이나 도구 요청에 오류가 남을 수 있다. **생성과 별도로 초안을 다시 검토하고, 피드백에 따라 수정하면 놓친 정보나 잘못된 판단을 바로잡을 수 있을 것**이라고 예상했다.

## Setup

- **평가 대상:** `airline 42`, trial 0 한 건. 설정상 3회였지만 첫 실행 완료 후 중단했으며, 미완료 실행은 결과에 포함하지 않았다.
- **적용 방식:** 첫 실험의 조회·대조 지침을 유지하고, 답변·도구 요청마다 `초안 생성 → 검토 → 필요하면 수정·재검토`를 수행했다. 최종 선택된 도구 요청만 실제로 실행했다.
- **모델:** 생성·검토·수정과 User Simulator 모두 Gemma 4 12B (QAT Q4_0)를 사용했다. 실행 서버는 Ollama였다.
- **검토 설정:** 초안당 최대 수정 2회. 검토 승인 시 종료하고, 오류나 수정 상한에 도달하면 마지막 초안을 반환하도록 했다.
- **평가 설정:** seed `42`에서 파생된 trial seed `670487`, 동시 실행 `1`, 최대 step `200`, 최대 오류 `10`.

### 추가 채점

저장된 실행 기록을 `gpt-6-astra (high)`로 채점한 공통 항목의 결과다. 두 열은 각각 실행 한 건이며, 실행 중 검토 모델의 승인과는 별개의 사후 판정이다.

| 기준            | 지침 추가만 적용 | 지침 추가 + Reflection |
| --------------- | ---------------- | ---------------------- |
| 조회 근거       | 실패             | 통과                   |
| 제안 적절성     | 실패             | 통과                   |
| 사용자 동의     | 통과             | 통과                   |
| 요청·정책 준수 | 통과             | 통과                   |

일부 공통 항목은 나아졌지만, task별 판정에서는 필요한 예약 `FDZ0T5`의 식별·취소, 타인 예약 `SE9KEL`의 제외, 기존 왕복 예약 `5BGGWZ`의 귀환 구간 인식에 실패했다. 실제로는 `HSR97W`와 함께 `SE9KEL`, `MFRB94`를 취소하고 `FDZ0T5`를 남겼다.

‘제안 적절성’과 ‘요청·정책 준수’의 통과가 원래 task의 올바른 완료를 뜻하지는 않는다. 저장된 judge는 잘못된 예약 분류 이후 사용자가 명시적으로 요청·승인한 취소와 정책 준수를 공통 항목에서 인정했고, 최초 분류·안내 오류와 task의 대상 제외 실패는 별도로 판정했다.

### 검토 과정에서 확인한 내용

완료된 실행에 연결된 기록에는 검토 21회와 수정 3회가 있었다.

- **보완한 부분:** 예약 하나를 조회하지 않은 초안에서 누락을 발견했고, 수정 후 해당 예약을 조회했다. 나머지 두 수정 요청은 답변과 도구 호출의 동시 출력, 상담원 이관 절차에 관한 것이었다.
- **놓친 부분:** 모든 예약을 조회한 뒤에도 취소해야 할 예약을 유지 후보로 분류하고, 왕복 예약의 귀환 구간을 잘못 해석했다. 검토 모델은 이 내용이 담긴 초안을 수정 없이 승인했다.

즉, 검토·수정 절차는 실제로 작동했지만 조회한 정보를 올바르게 해석하는 오류까지 잡아내지는 못했다.

### 결론

**첫 실행에서 일부 조회·절차 오류는 보완했지만, 목표로 한 대상 판단 개선과 올바른 작업 완료는 달성하지 못했다.** 추가 검토를 거친 내용에도 핵심 오류가 남았으며, 검토 승인이 정확한 판단을 보장하지 않았다.

한 실행에 약 42분이 걸린 점과 첫 결과에서 유의미한 목표 성능 향상을 확인하지 못한 점을 고려해 실험을 중단했다.
